# Maar contrastive steering — prompt sets and outputs

Artefacts for [`examples/maar_contrastive_steering.rs`](../../maar_contrastive_steering.rs)
(Maar et al. 2026 replication, v0.1.12).

## Layout

```
prompts/                Prompts JSON files (input)
  # candle-mi-authored (Step B fallback; produced by scripts/regenerate_rhyme_prompts.py)
  gemma2_rhyme_ee.json
  gemma2_rhyme_out.json
  llama32_1b_rhyme_ee.json
  llama32_3b_rhyme_ee.json

  # maar-supplementary verbatim (Step A; produced by scripts/convert_maar_prompts.py
  # from the extracted maar_supp/ tree; this is what the rebuttal calibration uses)

  llama32_1b_rhyme_ee_maar.json

maar_supplementary.zip  (gitignored; downloaded via scripts/maar_supplementary_fetch.py
                         if accessible — typically requires a logged-in OpenReview session)
maar_supp/              (gitignored; extracted supplementary tree, 60 MB of Maar's code +
                         data; the *_maar.json prompts above are the only artefacts
                         derived from it that get committed to the repo)
```

[`docs/experiments/maar-replication/`](../../../docs/experiments/maar-replication/)

## Prompts JSON schema

```json
{
  "family": "-ee",
  "template": "A rhyming couplet:\n{line}",
  "positive": [
    "A rhyming couplet:\nI saw a robin in the apple tree",
    ...
  ],
  "negative": [
    "A rhyming couplet:\nThe lantern light went suddenly clean out",
    ...
  ],
  "eval": [
    {
      "prompt": "A rhyming couplet:\nI saw a robin in the apple",
      "target_token": " tree",
      "target_rhyme_words": [" tree", " sea", " free", " three", " bee", ...]
    },
    ...
  ],
  "source": "candle-mi-authored" | "maar-supplementary",
  "source_url": null | "<openreview URL>"
}
```

## Provenance

Each prompts file records its `source`:

- `"candle-mi-authored"`: generated by
  [`scripts/regenerate_rhyme_prompts.py`](../../../scripts/regenerate_rhyme_prompts.py)
  from hand-curated couplet stems + CMUdict-validated rhyme word lists,
  following Maar's *described* structure (85 positive + 85 negative + 20
  held-out eval per family, template `"A rhyming couplet:\n{line}"`).
  Used in early v0.1.12 exploration runs (Run #1 single-forward sweep,
  Run #2 generated-couplet w/o Maar prompts).
- `"maar-supplementary"`: extracted verbatim from Maar's OpenReview
  supplementary `.zip` (file names `*_maar.json`).  Produced by
  [`scripts/convert_maar_prompts.py`](../../../scripts/convert_maar_prompts.py)
  which parses Maar's `paper_experiments/data/{train,test}/rhyme_family_lines.json`
  plus the `rhyme_family_words` dict embedded in `shared_utils.py`.
  This is what the v0.1.12 rebuttal calibration uses (Run #3 + the
  three strength sweeps in [`docs/experiments/maar-replication/`](../../../docs/experiments/maar-replication/)).
  Reproducible: `python scripts/convert_maar_prompts.py` rewrites these
  byte-identically from the gitignored `maar_supp/` tree.

Both source modes are valid for v0.1.12 deliverables; the
`"maar-supplementary"` mode is strictly more faithful and is the one used
for the headline calibration results.  The `source` field on every output
JSON makes the choice auditable.
